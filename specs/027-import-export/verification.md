# Verification: Import and Export of Catch Records

The code built on assumptions only the game can confirm carries `-- VERIFY(<id>): <what>`; the IDs continue the V
series (V77 was spec 026's; this spec has V78, V79 and V80). A marker is removed after the author confirms the behaviour in game,
or when the author accepts the assumption without a check (the row then says "Accepted" and what happens if it is
wrong).

| ID | Assumed | Where | If wrong | Check | Status |
|---|---|---|---|---|---|
| V78 | A multi-line `EditBox` with `SetMaxLetters(0)` shows, selects and copies an export of up to 256 KB, and takes a paste of the same size whole, without a freeze worth noting | `Exchange/ShareTransfer.lua` `EXPORT_LIMIT`, `UI/TransferPage.lua` | A long paste is cut, so the import refuses it as cut and nothing is lost; lower `EXPORT_LIMIT` to the size that passes | Export from an account whose store gives a string near the limit (the hint says its size), copy it, paste it on the other account's page and import: the counts must cover every record ([checklist](../../docs/checklists/import-export.md), step 5) | Accepted 2026-11-26 by the author without a check near 256 KB: exports of 110, 138, 144 and 149 KB were shown and copied whole in game, and the 110 KB and 138 KB ones were pasted and imported whole. If a longer one is cut by the box, the import answers "incomplete" and stores nothing; then lower `EXPORT_LIMIT` to the size that passes |
| V79 | The game's `WowStyle1DropdownTemplate` (`CreateFrame("DropdownButton", ...)`, `SetupMenu` with two `CreateRadio`) shows the chosen radio's text on its button, and `GenerateMenu()` called from a radio's own callback updates it | `UI/TransferPage.lua` (the selector) | The button shows the wrong choice or no text; fall back to the plain button with a menu (the code's branch for a client without the template) | Open the page, pick each choice from the list: the button names the chosen one, the menu closes, the area changes ([checklist](../../docs/checklists/import-export.md), step 2) | Confirmed 2026-11-26: the list's button read "Export my data" after picking it and "Import a string" again after picking that, on two characters and in two languages (English, Ukrainian) |
| V80 | A paste into the Import box runs `OnChar` for every character, also those over the box's `SetMaxBytes` (2048), so the joined characters are the whole string while the box lays out only its start (a 110 KB paste into a box without a limit froze the game for 4 to 6 s, 2026-11-26) | `UI/TransferPage.lua` (`OnChar`, `frame.Pasted`) | The import gets only the first 2 KB and answers "incomplete"; then paste into a hidden box or split the string | Paste a string of 100 KB or more on Import: no freeze worth noting, the hint says "Pasted N KB" with the size the export named, and Import brings every record ([checklist](../../docs/checklists/import-export.md), step 5) | Confirmed 2026-11-26: a 138 KB export of 320 records (Horde) pasted on an Alliance character in about half a second (4 to 6 s before the change), the hint said "Pasted 138 KB", the import answered 103 new, 217 known, 0 own, 0 refused, and the same string again 0 new, 320 known |
