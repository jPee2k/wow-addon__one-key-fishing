# Verification: Fishing Camp Buffs

The code built on assumptions only the game can confirm carries `-- VERIFY(<id>): <what>`; the IDs continue the V
series (V59 was spec 019's). A marker is removed after the author confirms the behaviour in game, or when the author
accepts the assumption without a check (the row then says "Accepted" and what happens if it is wrong).

Already seen in game (2026-11-19, [docs/fishing-investigation.md](../../docs/fishing-investigation.md), "Checked in
game"), no marker: the Fishing Rack's aura 1280341 is read by ID out of combat and not in a fight; the `UNIT_AURA`
payload is secret in a fight; the aura comes in the second of the placing, also to a party member, lasts one hour,
outlives the Rack and a relog; the cast, the bobber and the loot source are the same under it; the bonus is a second
loot slot of the same catch; Camper's Lure (291005) is a weapon enchant of +60 for 5 minutes that needs Fishing 50.
