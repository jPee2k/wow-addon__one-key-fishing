# Verification debt: Fishing Sounds

Claude cannot run the game. The fishing sounds are built on the assumptions below, read from the client export
(build 1.60.1.70685) and Ketho's Forever resources but not seen in game. The IDs continue the V series of specs 002
to 009 (V1 to V45); V50 was added by the review of 2026-11-16. The code carries `-- VERIFY(Vnn): ...`; `npm run check` lists them, and `npm run build` refuses to
package while one is open.

To close an item:
1. Run its step in game (`docs/checklists/sounds.md`).
2. Record the answer in `docs/forever-api.md`.
3. Adjust the code if the game differs.
4. Remove the marker and tick the item here.
